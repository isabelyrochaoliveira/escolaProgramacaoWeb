# Patas e Laços - Plataforma de Adoção de Pets

Aplicação web interativa desenvolvida em **Python** e **Streamlit** com persistência no **Firebase Firestore**, criada para conectar animais disponíveis para adoção a novos lares.

---

## Funcionalidades

- **Vitrine de Pets:** Visualização em grid com filtros dinâmicos por status de adoção, porte e sexo.
- **Cadastro de Pets:** Formulário completo para inclusão de novos animais, com suporte a upload de fotos e validação de campos.
- **Gerenciamento e Edição:** Painel administrativo para atualizar informações, alterar status (Disponível/Adotado) e exclusão de registros.
- **Integração com Banco de Dados:** Persistência em tempo real e em nuvem via Google Cloud Firestore.

---
